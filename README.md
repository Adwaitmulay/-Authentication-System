# Authentication System — Login & Signup

A complete frontend authentication system built using HTML, CSS and JavaScript with localStorage for data storage.

## Pages
- signup.html — Create a new account with full validation
- login.html — Login with email and password
- dashboard.html — Protected page shown after login

## Features
- Full client-side form validation
- Password strength checker
- Duplicate email detection
- Session management using sessionStorage
- User data stored in localStorage
- Protected dashboard — redirects to login if not logged in
- Mobile responsive design
